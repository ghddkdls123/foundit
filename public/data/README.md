`regions.geojson` contains simplified Korean province boundaries from the KOSTAT 2013 dataset in the `southkorea/southkorea-maps` repository.

Source: https://github.com/southkorea/southkorea-maps/tree/master/kostat/2013/json
The source repository states that KOSTAT data is free to share or remix. The Jeonnam and Gwangju geometries are grouped as `전남` to match Foundit's API region values.
